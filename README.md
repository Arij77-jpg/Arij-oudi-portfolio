# Arij Oudi — Personal Portfolio

A modern, responsive developer portfolio built with pure **HTML5, CSS3, and Vanilla JavaScript**, tailored from Arij Oudi's CV.

## Features
- **Sleek Dark Tech / AI & DevOps aesthetic** with a persistent **Dark / Light mode toggle** (`localStorage`).
- **Interactive Hero** with constellation particle canvas, dynamic role typing animation, and terminal-style JSON profile card.
- **Complete CV Showcase**:
  - **About & Education**: Horizon School of Digital Technology, Double Degree with Beijing Polytechnic, Dual Degree with Collège de Paris, and High School Diploma (2024).
  - **Projects**: Filterable project showcase (*Bledi+ (بلادي+)*, *HorizonExam*, *The Snitch's Path*, *Adventure Time Treasure Hunt*, and Robotics projects) with interactive detail modals.
  - **Skills**: Programming, Web & Databases, DevOps/Tools/AI, and Methodologies.
  - **Certifications & Leadership**: NVIDIA, Meta, HP LIFE, 15+ Robotics Certifications, and filterable Leadership & Achievements (HoriBot Club, GDSC, Delta Club, Nuit de l'Info, GAICA, etc.).
  - **Contact**: One-click copy email, direct contact links, and email composer form.

## Preview Locally
Simply double-click `index.html` to open it in any web browser, or run a quick local static server:
```powershell
npx serve .
```

## Deploy to GitHub Pages
1. Create a GitHub repository named `Arij77-jpg.github.io` (or any repository name).
2. Push `index.html`, `styles.css`, and `script.js` to the `main` branch.
3. In your repository **Settings → Pages**, set the source to the `main` branch (`/ (root)`).
